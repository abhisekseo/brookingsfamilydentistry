# Brookings Family Dentistry – Website Redesign

Single-page redesign of https://www.brookingsfamilydentistry.com/ (HTML, CSS and vanilla JS, no build step).

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
Settings > Pages > Deploy from a branch > `main` / root.

## Notes
- Images are embedded in `index.html` as base64.
- Appointment buttons and the form open an email to info@brookingsfamilydentistry.com (no booking backend).
- Several links still point to the existing Wix pages.
- The before/after slider uses illustrations, not patient photos.
- Confirm financial, insurance and FAQ wording with the practice before launch.
